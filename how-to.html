使い方 / How to use

Seamless Scatter Makerは、複数の画像素材からシームレスな散布パターンを作るブラウザツールです。

基本的な使い方

  1. PNGまたはSVG素材をドラッグ＆ドロップします。
  2. 各素材のグループ、重み、サイズ、回転、左右反転率などを調整します。
  3. キャンバスサイズと配置方式、配置数を選びます。
  4. 生成を押します。
  5. 必要ならプレビュー上の素材をドラッグして位置を微調整します。
  6. PNG書き出しで保存します。

メイン / サブ

メイン素材は先に全体へ散らされ、サブ素材はその後に空いた場所へ配置されます。 主役にしたい素材をメイン、装飾や補助素材をサブにすると調整しやすくなります。

シームレスについて

端からはみ出した素材は反対側にも描画されます。そのため、書き出したPNGを並べても境界がつながるように生成されます。

画像の扱い

読み込んだ素材は、このツール自身の処理ではサーバーへアップロードされません。 配置・合成・書き出しはブラウザ内で行われます。

English quick guide

  1. Drop PNG or SVG assets into the tool.
  2. Adjust each asset's group, weight, scale, rotation, and flip settings.
  3. Choose canvas size, placement mode, and target count.
  4. Press Generate.
  5. Drag placed assets in the preview for fine adjustments if needed.
  6. Press Export PNG.

Main assets are distributed first. Sub assets are then placed into the remaining space.
